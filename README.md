# LectureVault

Android-приложение для записи лекций и автоматического создания конспектов в Obsidian.

После остановки записи приложение:

1. отправляет небольшие аудиофрагменты на защищённый сервер LectureVault;
2. объединяет расшифровку с временными метками;
3. просит сервер создать структурированный Markdown-конспект;
4. записывает готовую заметку в выбранный vault Obsidian.

ПК для записи и обработки не нужен. Приложение рассчитано в первую очередь на Samsung Galaxy S22+ и другие Android-устройства с Android 8+.

## Что уже работает

- фоновая запись с постоянным уведомлением и кнопкой остановки;
- продолжение записи при заблокированном экране;
- M4A/AAC mono 16 кГц, 32 кбит/с;
- автоматическое деление записи на части по 20 минут;
- очередь обработки, переживающая закрытие приложения и перезагрузку;
- повторы для временных сетевых ошибок и понятная ошибка при недоступности сервера;
- кэширование уже расшифрованных частей без повторного расхода квоты;
- серверный Groq `whisper-large-v3-turbo`, русский язык, временные метки;
- Gemini с резервом через OpenRouter; ключи не хранятся в приложении;
- сохранение через Android Storage Access Framework без широкого доступа к файлам;
- история лекций, повтор неудачной обработки и открытие готовой заметки в Obsidian;
- защита от дублирования заметки после повтора или перезапуска.

## Установка для разработки

Требования:

- Android Studio Panda 4 или совместимая версия;
- JDK 17;
- Android SDK 36;
- телефон с включённой отладкой по USB либо Android Emulator.

Сборка debug APK:

```powershell
.\gradlew.bat assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый телефон:

```powershell
C:\Users\user\Android\Sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```

## Первичная настройка

### 1. Obsidian и папка vault

Создайте или откройте локальный vault в Obsidian на телефоне. Удобный путь на Samsung: `Внутренняя память/Documents/Obsidian/<название vault>`.

В LectureVault откройте настройки, нажмите «Выбрать папку vault» и выберите именно корневую папку этого vault. По умолчанию заметки создаются внутри `Учёба/Конспекты`.

Приложение никогда не пишет в `.obsidian` и не запрашивает доступ ко всей памяти устройства.

### 2. Облачная обработка

В настройках включите согласие на отправку аудио и текста на защищённый сервер ИИ.
Ключи Groq, Gemini и OpenRouter остаются только на сервере и не требуются пользователю.
Сервер использует Gemini, затем OpenRouter как резерв; при недоступности облака приложение
может обработать запись локальной моделью, если она скачана.

### 3. Бесплатная синхронизация Obsidian

Обычный аккаунт Obsidian не включает бесплатную синхронизацию. Для бесплатного варианта на каждом устройстве можно установить community-плагин [Remotely Save](https://github.com/remotely-save/remotely-save) и подключить один и тот же OneDrive или Dropbox.

Настройте синхронизацию при запуске Obsidian и после изменения файлов. LectureVault создаёт локальный `.md`; передачу между устройствами выполняет Remotely Save. Поэтому после готовности конспекта откройте Obsidian на записывающем телефоне, чтобы плагин отправил файл в облако. На другом устройстве Obsidian заберёт его при открытии/синхронизации.

Если используется платный Obsidian Sync, отдельный плагин не требуется.

### 4. Настройки Samsung

Чтобы длительную запись не остановила энергосберегающая система Samsung:

1. `Настройки → Приложения → LectureVault → Батарея`;
2. выберите «Без ограничений»;
3. разрешите микрофон и уведомления.

Приложение также держит ограниченный по времени wake lock во время записи и показывает неснимаемое уведомление.

## Использование

1. Введите название лекции и предмет.
2. Нажмите круглую кнопку микрофона.
3. После пары нажмите её снова либо «Остановить» в уведомлении.
4. Обработка запустится при наличии интернета. Экран можно выключить.
5. Когда заметка будет готова, нажмите уведомление или «Открыть в Obsidian» в истории.

При временном сбое сервера приложение повторит запрос с увеличивающейся задержкой. После пяти неудачных попыток в истории появится понятная ошибка и кнопка ручного повтора. Уже готовые части расшифровки повторно не отправляются.

## Ограничения бесплатного режима

- Бесплатные квоты провайдеров могут меняться или временно заканчиваться; сервер ограничивает публичный доступ по IP.
- Groq принимает не более 25 МБ за прямую загрузку на Free tier; приложение использует 20-минутные части и дополнительно отклоняет часть больше 24 МБ.
- Бесплатный Gemini может использовать отправленные данные для улучшения продуктов. Не записывайте приватные разговоры и получите разрешение преподавателя/участников.
- LectureVault создаёт заметки, но сам не авторизуется в аккаунте Obsidian и не подменяет Obsidian Sync.

Подробности обработки данных находятся в [PRIVACY.md](PRIVACY.md).
