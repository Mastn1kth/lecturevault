# Конфиденциальность LectureVault

LectureVault не имеет собственного сервера и не создаёт пользовательских аккаунтов.

## Какие данные обрабатываются

- Запись лекции хранится во внутреннем приватном каталоге приложения.
- Только после явного согласия каждый аудиофрагмент отправляется напрямую с устройства в Groq для распознавания речи.
- Полученная расшифровка отправляется напрямую в Google Gemini для создания конспекта.
- На Android при недоступности облака используется скачанная локальная русская модель. Если облачное согласие не дано, данные в Groq и Gemini не отправляются.
- Конспект и полная расшифровка записываются в выбранную пользователем папку Obsidian.
- Если пользователь настроил Obsidian Sync, Remotely Save, OneDrive, Dropbox или другой сервис, дальнейшая синхронизация регулируется условиями этого сервиса.

LectureVault не собирает рекламу, аналитику, контакты, местоположение, идентификаторы устройства или журнал браузера. В приложении отсутствует система crash-reporting и HTTP body logging.

## API-ключи

Groq и Gemini API keys шифруются отдельным AES-256-GCM ключом в Android Keystore. Шифротекст хранится в приватных SharedPreferences, а резервное копирование приложения отключено. Ключи не передаются между устройствами и не добавляются в Markdown.

На модифицированном/root-устройстве злоумышленник теоретически может перехватить ключ в памяти во время сетевого запроса. Для личного приложения используется модель BYOK: только ваш ключ и только на вашем телефоне.

## Удаление

API-ключи можно удалить кнопкой «Удалить» / «Удалить ключи» в настройках. Удаление приложения удаляет его приватные аудиозаписи, очередь и ключи устройства. Уже созданные заметки останутся в Obsidian, пока пользователь не удалит их самостоятельно.

## Важное предупреждение

Перед записью получите необходимое согласие преподавателя и других участников и соблюдайте правила учебного заведения и применимое законодательство. Не отправляйте через бесплатные API конфиденциальные, медицинские, финансовые или иные чувствительные сведения.

Актуальные правила обработки у внешних сервисов:

- Groq: <https://console.groq.com/docs/your-data>
- Google Gemini API Terms: <https://ai.google.dev/gemini-api/terms>
- Obsidian: <https://obsidian.md/privacy>
