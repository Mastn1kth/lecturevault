# LectureVault 1.2.0 — мобильное обновление

Дата: 10 сентября 2026.

## Что изменилось

- Android и iPhone используют одинаковую структуру главного экрана без слогана «Сохрани главное».
- Готовый конспект открывается для чтения прямо внутри приложения.
- Лекцию можно удалить из списка или с экрана чтения после обязательного подтверждения.
- На Android удаляются Markdown-файл из Obsidian и локальные аудиосегменты/метаданные.
- На iPhone удаляется выбранный Markdown-файл из подключённого vault Obsidian.

## Проверка

- Android: unit-тесты, lint и release APK успешно собраны на Windows.
- iPhone: выполнена статическая проверка исходников и project.yml; бинарная сборка требует macOS и Xcode.
