# LectureVault 1.3.0

Дата: 11 сентября 2026.

## Новые функции

- Фоновая обработка продолжается через WorkManager после закрытия приложения. Уведомление «Конспект готов» открывает нужную лекцию.
- В экране лекции появился аудиоплеер. Таймкоды расшифровки стали кликабельными и перематывают к нужному моменту.
- Появилась отдельная кнопка «Создать мини тест». Она локально строит до шести карточек «вопрос — ответ» из краткого конспекта.

## Проверка

- Android unit-тесты, lint, debug и release APK успешно собраны.
- Таймкоды облачной расшифровки учитывают номер аудиочасти, поэтому переход открывает правильный сегмент записи.
