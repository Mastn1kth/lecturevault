# LectureVault 1.5.7 — тестовая сборка

Тестовая Android-сборка для закрытого тестирования. Это не финальная публикация в Google Play.

## Что делает

Записывает или принимает готовое аудио пары, создаёт конспект Markdown для Obsidian, сохраняет аудио и умеет делать мини-тест из 10 вопросов.

## Установка

1. Скачайте APK ниже на Android 8.0+.
2. Разрешите установку из этого источника, если Android спросит.
3. Откройте приложение, разрешите микрофон и уведомления.
4. В настройках выберите корневую папку vault Obsidian — папку, внутри которой есть `.obsidian` — включите согласие на облачную обработку и сохраните.

## Если что-то не работает

- Если облако недоступно, заранее скачайте русскую локальную модель в настройках.
- Если конспект не появился на ПК, проверьте синхронизацию самого vault Obsidian.
- Не отправляйте API-ключи или пароли: приложению они не нужны.
