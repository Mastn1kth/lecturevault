# LectureVault 1.5.0

## Android

- В готовой лекции появилась кнопка «Сохранить аудиозапись».
- Пользователь выбирает папку на устройстве, а приложение копирует в неё все исходные аудиофрагменты лекции.
- Экспортированные файлы независимы от внутреннего хранилища: удаление лекции не удаляет сохранённые копии.
