# LectureVault 1.4.0

## Android

- «Создать мини тест» теперь запускает Gemini и создаёт ровно 10 вопросов по конспекту лекции.
- У каждого вопроса три варианта ответа; приложение сразу показывает, верен ли выбранный вариант.
- Перед показом результат Gemini проверяется: должны быть все 10 вопросов, по три уникальных варианта и корректный индекс правильного ответа.
- В Gemini отправляется только сохранённый Markdown-конспект, без аудиофайлов.
