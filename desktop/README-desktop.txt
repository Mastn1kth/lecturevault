LectureVault для Windows и macOS

Windows-пакет: распакуйте архив и запустите LectureVault.exe.

macOS portable:
1. Установите Java 17 или новее.
2. Запустите LectureVault.command. Если macOS не разрешает запуск, выполните
   chmod +x LectureVault.command, затем откройте файл ещё раз.

После запуска откройте «Настройки», вставьте ключи Groq и Gemini и выберите корневую
папку vault Obsidian. Затем введите предмет и начните запись или выберите аудиофайл.
